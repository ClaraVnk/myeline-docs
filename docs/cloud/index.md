# Cloud / Hébergé

L'édition **Cloud** est Myeline en version hébergée, accessible
directement sur [myeline.io](https://myeline.io) — **rien à
installer**. Vous créez un compte, connectez vos drives et vos sources,
et interrogez l'ensemble en langage naturel via RAG. La plateforme est
**hébergée en Europe (France)**, conforme RGPD.

[:material-rocket-launch: Créer un compte gratuit](https://myeline.io){ .md-button .md-button--primary }
[:octicons-arrow-right-24: Premiers pas](getting-started.md){ .md-button }

!!! info "Hébergé ou on-premise ?"
    Cette page couvre l'offre **hébergée** (Free / Pro). Si vous devez
    tout faire tourner sur **votre propre infrastructure** (air-gap,
    SecNumCloud, HDS), l'offre **On-premise / Souverain** est une
    installation **sur-mesure, sur devis** — voir
    [Choisir son édition](../editions/index.md) ou écrivez à
    [hello@myeline.io](mailto:hello@myeline.io).

## Pourquoi le Cloud ?

- **Zéro installation, zéro ops** : pas de serveur à provisionner, pas
  de mise à jour à gérer. On s'occupe de l'infra.
- **Données hébergées en UE / France** : embedding et synthèse via
  l'**API Mistral AI** (UE, pas d'entraînement sur les données API).
  Résidence des données européenne par défaut.
- **Démarrage immédiat** : compte créé, clé branchée (Free) ou Mistral
  inclus (Pro), et vous interrogez vos sources en quelques minutes.

## Comment ça marche

L'usage des fonctionnalités (recherche RAG, bibliothèque, connecteurs,
conversations, veille) est **commun à toutes les éditions** et décrit
dans les [Concepts (toutes éditions)](../concepts/index.md). Côté Cloud,
il n'y a aucune étape d'infrastructure : vous passez directement à la
configuration de votre compte.
