# Cloud / Hosted

The **Cloud** edition is the hosted version of Myeline, available
directly at [myeline.io](https://myeline.io) — **nothing to install**.
You create an account, connect your drives and sources, and query
everything in natural language via RAG. The platform is **hosted in
Europe (France)** and GDPR-compliant.

!!! info "Hosted or on-premise?"

    everything on **your own infrastructure** (air-gap, SecNumCloud,
    HDS), the **On-premise / Sovereign** offer is a **bespoke,
    quote-based** installation — see
    [Choose your edition](../editions/index.md) or email

## Why the Cloud?

- **Zero install, zero ops**: no server to provision, no upgrades to
  manage. We run the infrastructure.
- **Data hosted in the EU / France**: embedding and synthesis via the
  **Mistral AI API** (EU, no training on API data). European data
  residency by default.
- **Instant start**: account created, key plugged in (Free) or Mistral
  included (Pro), and you query your sources within minutes.

## How it works

Feature usage (RAG search, library, connectors, conversations, watch)
is **shared across all editions** and described in the
[Concepts (all editions)](../concepts/index.md). On the Cloud there is
no infrastructure step: you go straight to configuring your account.
